# Review a Spec

Execute this Workflow for one assigned Spec review mandate.

Read once; reread as needed: `<BWR_SKILL>/prompts/contracts/spec/current-spec.md`.

## Read the subject

Read the assigned Current Spec in full.

Read every additional input required by your Role. Treat the assigned Spec path and input set as the complete review subject.

## Prepare risk filtering

Risk filtering applies to these mandates:

- `enumerator`;
- `verifier`;
- `judge`;
- `ripple`;
- `scoped`.

For one of these mandates:

1. Read once; reread as needed: `<BWR_SKILL>/prompts/references/review/risk-filtering.md`.
2. Read the assigned `PRIVATE_HISTORY` file when it exists.
3. Use the current Round identifier as the occurrence label.

## Review

Execute your complete Role mandate against the complete assigned subject.

Collect concrete evidence for every candidate problem. Apply the Finding, Severity, and applicable risk-filtering rules.

Confirm that the applicable private history contains every filtered candidate from this assignment.

Complete the Reviewer completion procedure.

## Exit

- Handoff sent → wait for parent action.
- Follow-up received for this assignment → execute this Workflow again with the updated inputs.
