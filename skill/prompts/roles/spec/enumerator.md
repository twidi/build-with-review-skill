# Spec Enumerator

Perform an exhaustive mechanical review of the assigned Spec.

Check every:

- internal reference;
- cited path, symbol, command, and test;
- closed value list;
- required identifier and identifier format;
- count and absolute statement;
- table definition;
- named behavior without a validation method.

Follow each check across the complete Spec. Do not sample occurrences.

Keep the mandate mechanical. Report checkable mismatches and omissions found through these checks.
