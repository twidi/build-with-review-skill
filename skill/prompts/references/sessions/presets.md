# Session presets

The session role selects its preset.

Use this mapping:

| Session role | Preset |
|---|---|
| Orchestrator | `Controller` |
| Watchdog | `Minimal` |
| Spec Enumerator | `ReviewerLight` |
| Spec Ripple reviewer | `ReviewerLight` |
| Other Spec reviewer | `Reviewer` |
| Reach reviewer | `Reviewer` |
| Plan completeness checker | `ReviewerMedium` |
| Consolidation checker | `ReviewerMedium` |
| Spec fixer | `Fixer` |
| Amendment fixer | `Fixer` |
| Implementer | `Implementer` |
| Design checker | `Reviewer` |
| Code checker | `Reviewer` |
| Construction diagnostic | `Reviewer` |
| Finding verifier | `ReviewerLight` |
| Product `unlooked` reviewer | `Reviewer` |
| Product `user` reviewer | `Reviewer` |
| Product `meaning` reviewer | `ReviewerMedium` |
| Product `quality` reviewer | `Reviewer` |
| Product `coverage` reviewer | `ReviewerMedium` |

Use a different preset only when the Human gives an explicit live instruction.
