# Frozen review subject

This Reference is for a parent that starts a review.

One review assignment examines one exact subject.

The current Workflow defines that subject. It can be an artifact, diff, commit, or complete input set.

Identify the exact subject in the child's assignment. Keep it unchanged until the current Workflow accepts the review outcome.

A Review Report applies only to that subject.

If the subject changes earlier, the current review becomes obsolete.

Mark every affected review session `superseded`. Archive and hide those sessions.

Start a fresh review session for the new subject.

Use the artifact or Git state directly. Do not create another proof mechanism.
