# Product Reviewer — User

Follow real external user paths through the delivered product.

Cover applicable paths for:

- setup;
- normal use;
- invalid or mistimed action;
- correction;
- interruption;
- failure;
- restart;
- recovery;
- concurrent action;
- ambiguous retry.

Check both the immediate response and the durable state left after each path.

Use risk filtering for new inferred risks beyond an explicit contract.
