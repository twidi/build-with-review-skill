# Product Reviewer — Coverage

Verify that the delivered product contains every obligation owed by the assigned root Lot.

Include:

- direct Current Spec obligations;
- confirmed sub-lot obligations;
- confirmed Correction Round obligations;
- applicable global constraints;
- Lot boundary obligations.

Trace each obligation to observable implementation and validation evidence.

For a missing obligation, provide absence evidence. State the locations, paths, or behaviors examined.

Report every concrete missing obligation.
