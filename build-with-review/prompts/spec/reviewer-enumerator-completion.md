# Completion block — enumerator

**7 items.** Your report opens with this block, above the findings, and you paste it verbatim into your `parent` message. How to fill it: `completion-rules.md`.


    COMPLETION (7 items)
    - [ ] cross-references — N checked, N unresolved
    - [ ] paths and symbols — N checked, N nonexistent
    - [ ] totalizing claims — N checked, N false
    - [ ] enumerated value sets — N checked, N mismatched
    - [ ] decision rows — N checked, N missing a definition or a verification
    - [ ] named tests — N checked, N without a file or a runner
    - [ ] counts stated in the document — N recomputed, N stale

## For this mandate

- Every item here is exhaustible. A `NOT DONE` on one of them means the list was not finished, and the controller reads it that way.
